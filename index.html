Site Mapping

Each legacy site_id and the 3.0 Site* it becomes. The legacy name from the sites export is used by default; where that name isn't in the template's Site dropdown the row is flagged and the upload would be rejected, so pick a real 3.0 Site (or type an override). Picks are sticky across re-runs.

Location Type Mapping

Legacy's location_type_id is usually -1 (never set), so this is normally a single pick applied to every row. Choose the 3.0 Location Type* each legacy ID becomes. Picks are sticky across re-runs.

Crop Mapping

Legacy exports crop_id with no name attached. Upload a crops lookup (slot 3) for reliable suggestions; otherwise each suggestion is inferred from that ID's own location names and is shown with a confidence score — check the low-confidence ones. Note that Legacy often tags non-crop locations (an office, a shop) with a crop ID; those rows still need a Crop & Variety* value, and their Location Type* is better set per-row in the preview.
